# Orders Hub

Orders Hub is the internal tool the sales and finance teams use to look up orders, check monthly totals and
export reports.

## Who uses it

- Sales leads check their region's orders each morning.
- Finance exports the monthly summary for the board pack.
- Support looks up an order when a customer calls.
