# Exporting reports

Open **Summary**, choose the months you need and select **Export**. Orders Hub's export is a CSV file with one row
per month: month, orders, units and revenue.

Revenue is shown with two decimals. If you open the file in a spreadsheet and see `0.2` instead of `0.20`, format
the column as a number with two decimals; the file itself is correct.

Large exports (more than 24 months) are emailed to you instead of downloaded. The email comes from Orders Hub
within ten minutes.
