# Lab 02 resources

- `without-the-plan-edit/`: a build of the export where the plan was not edited. Its tests pass and its file
  writes `2085.7`. Use it when your own run already got the format right, to see what the plan edit protects
  against. Written for this lab and run with Python's `unittest`; not a recorded Copilot run.

The project's data, `project/data/orders.csv`, is synthetic: 97 order lines from January to June 2026, written
for these labs under the repository's [MIT licence](../../LICENSE). No real people, companies or orders.
