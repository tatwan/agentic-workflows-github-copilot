# Lab 04 resources

- `rules/copilot-instructions.md`: the team rules you add in Part B. In the project they live at
  `.github/copilot-instructions.md`.
- `rules/reviews.instructions.md`: the rule for review files you add in Part C. In the project it lives at
  `.github/instructions/reviews.instructions.md`.
- `without-the-rules/CR-104.md`: a review of CR-104 written the way an agent might write it with no team rules: a
  suggested owner taken from the background notes, "Approve" for something nobody has built, a claim that the tests
  pass with no test run, and its own headings. Use it in Part A if your run looked fine, to see what the rules are
  there to catch. We wrote this example for this lab; it is not a recorded Copilot run.

The requests, the report code and its data in `project/` are fictional, written for these labs under the
repository's [MIT licence](../../LICENSE). No real people, companies or orders.
