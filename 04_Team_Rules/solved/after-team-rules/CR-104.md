# Review: CR-104 Monthly report as a CSV file

Owner: unassigned

The request asks for the monthly summary as a CSV file with month, orders, units and revenue, revenue with two
decimals. `monthly_summary` in `orders/report.py` already returns those four values for each month, and revenue is
a `Decimal`, so two decimals can be kept.

Nothing has been built for this request, and no test was run for this review. `tests/test_report.py` tests the
summary, not a CSV file.

Checks still to run once the export exists: the tests in `tests/test_report.py`, plus a new test that the January
line of the file is `2026-01,8,174,2085.70`.
