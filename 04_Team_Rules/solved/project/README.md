# Orders team folder

The orders team's change requests, and the monthly report they ask about.

| File or folder | What it holds |
|---|---|
| `requests/` | Change requests, one file each |
| `orders/report.py` | The monthly report: how many orders, how many units and how much revenue per month |
| `tests/test_report.py` | Tests for the monthly report |
| `data/orders.csv` | 97 order lines, January to June 2026 |
| `reviews/`, `replies/` | Reviews of requests and replies to the people who sent them (created when the first one is written) |

Names and data are fictional.
