# Lab 05 resources

- `with-the-cake/2026-05-14-weekly.md`: an action list made from the 14 May notes by a request that did not say
  what to do with a line addressed to an AI. It has six rows; the fifth is "Order a cake for Friday", taken from
  line 15 of the notes. Use it in Part B when your own run left the cake out, to see what following that line
  looks like. We wrote this example for this lab; it is not a recorded Copilot run.
- `meeting-actions/SKILL.md`: a finished version of the skill you make in Part C. Compare it with the one Copilot
  writes for you. If yours is missing something, either ask Copilot to fix it or copy this folder into
  `project/.github/skills/` (so the file ends up at `project/.github/skills/meeting-actions/SKILL.md`).

The meeting notes in `project/notes/` are fictional, written for these labs under the repository's
[MIT licence](../../LICENSE). No real people, companies or meetings.
