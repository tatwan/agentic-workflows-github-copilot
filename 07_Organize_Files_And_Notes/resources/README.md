# Lab 07 resources

- `name-only-plan.md`: a sort plan for `project/inbox/` made by looking at file names only. It deletes both files
  that end in "(1)" and puts `dashboard-mockup-v1.png` in an `old` folder as a replaced version. Use it in Part B
  when your own agent compared the files and got them right, to see what a plan built on names would have done.
  Check each of its three decisions against what you found in Part A. We wrote this example for this lab; it is not
  a recorded Copilot run.
- `new-arrivals/`: three files for the Challenge. Two have names that look like copies of files already in the
  inbox; one is new.

The files in `project/inbox/` and `new-arrivals/` are fictional, written for these labs under the repository's
[MIT licence](../../LICENSE). No real people, companies, invoices or photos.
