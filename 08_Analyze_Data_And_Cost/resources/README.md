# Lab 08 resources

- `with-cancelled/q1-sales.md` and its chart `revenue-by-month.svg`: a report made from
  `project/data/orders-2026-q1.csv` that counts all 40 orders, the 3 cancelled ones included. Gift box shows
  276.00 and comes out as the top product, and March looks lower than February. Use it in Part C when your own
  report left the cancelled orders out, to see what counting them does to the story. We wrote this example for this
  lab with a short script; it is not a recorded Copilot run. Open the `.md` file with **Open Preview** to see the
  chart.

The orders in `project/data/` are fictional, written for these labs under the repository's
[MIT licence](../../LICENSE). No real shop, customers or sales.
