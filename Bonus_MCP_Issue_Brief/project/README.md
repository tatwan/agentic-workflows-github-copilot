# External-source brief

`task.md` points to a public issue. The issue body is deliberately absent: retrieve it through the configured
MCP tool, then write a brief in `briefs/`. No application code or packages are needed.
If GitHub MCP is unavailable, use the Microsoft Learn alternative described in the lab guide and save
`briefs/learn-mcp.md` instead. A prepared snapshot is an offline comparison, not a live retrieval.
