# Prepare an implementation brief

Read public GitHub issue https://github.com/github/github-mcp-server/issues/1 through the GitHub MCP server.
Write a local brief in `briefs/issue-1.md`: source URL, issue number/title, observed state and retrieval date;
three requirements grounded in the issue body; proposed checks; and open questions.

Keep proposed checks and questions distinct from source facts. This is a historical issue: a closed state is
useful evidence, not a reason to claim you implemented it. Leave GitHub unchanged.
