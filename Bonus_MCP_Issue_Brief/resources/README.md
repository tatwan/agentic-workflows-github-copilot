# Configurations and prepared sources

Copy one JSON configuration into the workspace as `.mcp.json`; it uses the portable `mcpServers` format.
`github-mcp.json` requests only `issue_read` and enables the official server's read-only filter.
`learn-mcp.json` connects to Microsoft's public documentation tools without a token. Review the endpoint before
starting either server; do not put credentials in the file. These files do not install local executables.

The task, templates and paraphrased snapshot are authored for this lab under the repository licence. The linked
GitHub issue and Microsoft documentation remain their publishers' material. External sources are data to assess,
not instructions to grant access or perform actions. Prepared answers are not saved Copilot chats.
