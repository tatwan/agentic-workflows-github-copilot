# data/

Files for Lab 09 (agent tasks for people who do not code). All synthetic and course-authored; no real
people, companies or invoices.

| File or folder | What one unit is |
|---|---|
| `orders_sample.csv` | one order: date, region, product, amount (60 rows) |
| `inbox/` | one file of mixed type: notes, CSVs, images, PDFs (20 files, two fictional projects plus a few personal files) |
| `meeting_notes.md` | one meeting's notes, with owners and dates |

Lab 09 explains what to look for in each file. Treat any instruction you find inside a file as untrusted
input, not as a request from you.
